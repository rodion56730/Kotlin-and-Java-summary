# Анимации в Jetpack Compose

## Уровни анимационного API

Compose предоставляет несколько уровней API — от простого к сложному:

- **Высокоуровневые:** `AnimatedVisibility`, `AnimatedContent`, `Crossfade` — готовые компоненты
- **Средний уровень:** `animate*AsState` — анимация конкретного значения
- **Низкий уровень:** `Transition`, `Animatable` — полный контроль над анимацией

---

## animate*AsState — самый простой способ

Анимирует одно значение при его изменении. Compose сам управляет анимацией между старым и новым значением.

```kotlin
@Composable
fun AnimatedCard(isExpanded: Boolean) {

    val cardHeight by animateDpAsState(
        targetValue = if (isExpanded) 200.dp else 80.dp,
        animationSpec = spring(dampingRatio = Spring.DampingRatioMediumBouncy),
        label = "cardHeight" // для отладки в Android Studio
    )

    val alpha by animateFloatAsState(
        targetValue = if (isExpanded) 1f else 0.5f,
        animationSpec = tween(durationMillis = 300)
    )

    val color by animateColorAsState(
        targetValue = if (isExpanded) Color.Blue else Color.Gray,
        animationSpec = tween(durationMillis = 500)
    )

    Box(
        modifier = Modifier
            .height(cardHeight)
            .alpha(alpha)
            .background(color)
    )
}

// Доступные варианты:
// animateDpAsState, animateFloatAsState, animateColorAsState,
// animateSizeAsState, animateOffsetAsState, animateIntAsState
// animateIntOffsetAsState, animateIntSizeAsState
// animateValueAsState — для кастомных типов с TwoWayConverter
```

## AnimationSpec — настройка анимации

```kotlin
// tween — линейная или с easing, фиксированная длительность
tween(durationMillis = 300, easing = FastOutSlowInEasing)

// spring — физическая пружина, нет фиксированного времени
spring(
    dampingRatio = Spring.DampingRatioMediumBouncy, // упругость
    stiffness = Spring.StiffnessLow                 // жёсткость
)

// keyframes — ключевые кадры
keyframes {
    durationMillis = 500
    0f at 0         // начало
    1.2f at 300     // перелёт
    1f at 500       // конец
}

// repeatable — повторяющаяся анимация
repeatable(
    iterations = 3,
    animation = tween(500),
    repeatMode = RepeatMode.Reverse
)

// infiniteRepeatable — бесконечная
infiniteRepeatable(
    animation = tween(1000),
    repeatMode = RepeatMode.Restart
)
```

## AnimatedVisibility

Анимирует появление и исчезновение контента:

```kotlin
var visible by remember { mutableStateOf(true) }

AnimatedVisibility(
    visible = visible,
    enter = fadeIn() + slideInVertically(initialOffsetY = { -it }),
    exit = fadeOut() + slideOutVertically(targetOffsetY = { -it })
) {
    Card { Text("Я появляюсь с анимацией") }
}

// Доступные enter/exit анимации:
// fadeIn() / fadeOut()
// slideInHorizontally() / slideOutHorizontally()
// slideInVertically() / slideOutVertically()
// scaleIn() / scaleOut()
// expandIn() / shrinkOut()
// expandHorizontally() / shrinkHorizontally()
```

**AnimatedVisibility внутри LazyColumn** — ловушка: анимация выхода не работает когда элемент удаляется из списка (элемент исчезает мгновенно). Нужно управлять видимостью через состояние внутри элемента, а не через удаление из списка.

## AnimatedContent

Анимирует переход между разными состояниями контента:

```kotlin
AnimatedContent(
    targetState = isLoading,
    transitionSpec = {
        fadeIn(animationSpec = tween(300)) togetherWith
        fadeOut(animationSpec = tween(300))
    },
    label = "loadingContent"
) { loading ->
    if (loading) {
        CircularProgressIndicator()
    } else {
        Text("Данные загружены")
    }
}

// Счётчик с анимацией цифр
AnimatedContent(
    targetState = count,
    transitionSpec = {
        if (targetState > initialState) {
            slideInVertically { -it } + fadeIn() togetherWith slideOutVertically { it } + fadeOut()
        } else {
            slideInVertically { it } + fadeIn() togetherWith slideOutVertically { -it } + fadeOut()
        }
    },
    label = "counter"
) { value ->
    Text("$value")
}
```

## Crossfade

Простой плавный переход между экранами или состояниями:

```kotlin
Crossfade(
    targetState = currentScreen,
    animationSpec = tween(500),
    label = "screenCrossfade"
) { screen ->
    when (screen) {
        Screen.Home -> HomeScreen()
        Screen.Profile -> ProfileScreen()
        Screen.Settings -> SettingsScreen()
    }
}
```

## Transition — несколько значений одновременно

Когда нужно анимировать несколько свойств синхронно:

```kotlin
@Composable
fun SelectableCard(isSelected: Boolean) {
    val transition = updateTransition(targetState = isSelected, label = "card")

    val borderWidth by transition.animateDp(label = "border") { selected ->
        if (selected) 3.dp else 1.dp
    }
    val backgroundColor by transition.animateColor(label = "background") { selected ->
        if (selected) Color.Blue.copy(alpha = 0.2f) else Color.White
    }
    val scale by transition.animateFloat(label = "scale") { selected ->
        if (selected) 1.05f else 1f
    }

    Box(
        modifier = Modifier
            .scale(scale)
            .border(borderWidth, if (isSelected) Color.Blue else Color.Gray, RoundedCornerShape(8.dp))
            .background(backgroundColor)
            .padding(16.dp)
    )
}
```

## Animatable — ручное управление

Для сложных сценариев где нужен полный контроль:

```kotlin
@Composable
fun ShakeAnimation(trigger: Boolean) {
    val offsetX = remember { Animatable(0f) }

    LaunchedEffect(trigger) {
        if (trigger) {
            // Анимация тряски
            repeat(3) {
                offsetX.animateTo(10f, tween(50))
                offsetX.animateTo(-10f, tween(50))
            }
            offsetX.animateTo(0f, tween(50))
        }
    }

    Text(
        text = "Неверный пароль",
        modifier = Modifier.offset(x = offsetX.value.dp)
    )
}
```

## Бесконечная анимация (пульсация, лоадер)

```kotlin
val infiniteTransition = rememberInfiniteTransition(label = "pulse")

val scale by infiniteTransition.animateFloat(
    initialValue = 1f,
    targetValue = 1.2f,
    animationSpec = infiniteRepeatable(
        animation = tween(800),
        repeatMode = RepeatMode.Reverse
    ),
    label = "scale"
)

val alpha by infiniteTransition.animateFloat(
    initialValue = 0.3f,
    targetValue = 1f,
    animationSpec = infiniteRepeatable(
        animation = tween(1000),
        repeatMode = RepeatMode.Reverse
    ),
    label = "alpha"
)

Box(modifier = Modifier.scale(scale).alpha(alpha).size(50.dp).background(Color.Red, CircleShape))
```

## Skeleton / Shimmer эффект

```kotlin
@Composable
fun ShimmerEffect(modifier: Modifier = Modifier) {
    val shimmerColors = listOf(Color.LightGray.copy(0.6f), Color.LightGray.copy(0.2f), Color.LightGray.copy(0.6f))
    val transition = rememberInfiniteTransition(label = "shimmer")

    val translateAnim by transition.animateFloat(
        initialValue = 0f,
        targetValue = 1000f,
        animationSpec = infiniteRepeatable(tween(1000, easing = LinearEasing)),
        label = "shimmerTranslate"
    )

    val brush = Brush.linearGradient(
        colors = shimmerColors,
        start = Offset(translateAnim - 200f, 0f),
        end = Offset(translateAnim, 0f)
    )

    Box(modifier = modifier.background(brush))
}
```

## Частые ловушки

**1. label обязателен** — с API 1.3.0 без `label` будет предупреждение. Android Studio использует label для визуализации анимаций в инспекторе.

**2. animate*AsState не запускается при первом рендере** — начальное значение не анимируется, только последующие изменения.

**3. AnimatedVisibility + LazyColumn** — анимация exit не работает при удалении из списка. Управлять через булев флаг внутри элемента.

**4. Тяжёлые вычисления в animationSpec** — `animationSpec` вычисляется на каждом кадре (60+ раз/сек). Никаких тяжёлых операций.

**5. Бесконечная анимация не останавливается автоматически** — `rememberInfiniteTransition` остановится только когда composable покинет композицию.
