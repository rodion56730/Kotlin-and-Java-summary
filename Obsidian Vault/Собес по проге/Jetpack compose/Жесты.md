# Gestures в Jetpack Compose

## Уровни API жестов

Compose предоставляет несколько уровней для работы с жестами:

- **Высокоуровневые Modifier'ы** — `clickable`, `scrollable`, `draggable`, `swipeable`
- **Pointer Input** — `pointerInput` с `detectTapGestures`, `detectDragGestures` и т.д.
- **Низкоуровневый** — `awaitPointerEventScope` для полного контроля

---

## Clickable и базовые нажатия

```kotlin
// Простой клик
Box(modifier = Modifier.clickable { onClick() })

// С ripple-эффектом и семантикой
Box(
    modifier = Modifier.clickable(
        onClick = { onClick() },
        onLongClick = { onLongClick() },
        onDoubleClick = { onDoubleClick() },
        indication = rememberRipple(),
        interactionSource = remember { MutableInteractionSource() }
    )
)

// Без ripple-эффекта (например, для кастомной анимации)
Box(
    modifier = Modifier.clickable(
        indication = null,
        interactionSource = remember { MutableInteractionSource() }
    ) { onClick() }
)
```

## pointerInput — универсальный обработчик

```kotlin
Box(
    modifier = Modifier.pointerInput(Unit) {
        detectTapGestures(
            onTap = { offset -> println("Tap at $offset") },
            onLongPress = { offset -> println("Long press at $offset") },
            onDoubleTap = { offset -> println("Double tap at $offset") },
            onPress = { offset ->
                // onPress вызывается при нажатии, до отпускания
                tryAwaitRelease() // ждём отпускания
                println("Released")
            }
        )
    }
)
```

## Drag — перетаскивание

```kotlin
// Простое перетаскивание по одной оси
var offsetX by remember { mutableStateOf(0f) }

Box(
    modifier = Modifier
        .offset { IntOffset(offsetX.roundToInt(), 0) }
        .draggable(
            orientation = Orientation.Horizontal,
            state = rememberDraggableState { delta ->
                offsetX += delta
            }
        )
)

// Перетаскивание по двум осям
var offset by remember { mutableStateOf(Offset.Zero) }

Box(
    modifier = Modifier
        .offset { IntOffset(offset.x.roundToInt(), offset.y.roundToInt()) }
        .pointerInput(Unit) {
            detectDragGestures { change, dragAmount ->
                change.consume() // поглощаем событие чтобы не передавалось дальше
                offset += dragAmount
            }
        }
        .size(100.dp)
        .background(Color.Blue)
)
```

## Transformable — масштабирование и поворот

Пинч-зум и вращение одним Modifier'ом:

```kotlin
var scale by remember { mutableStateOf(1f) }
var rotation by remember { mutableStateOf(0f) }
var offset by remember { mutableStateOf(Offset.Zero) }

val state = rememberTransformableState { zoomChange, offsetChange, rotationChange ->
    scale *= zoomChange
    rotation += rotationChange
    offset += offsetChange
}

Box(
    modifier = Modifier
        .graphicsLayer(
            scaleX = scale,
            scaleY = scale,
            rotationZ = rotation,
            translationX = offset.x,
            translationY = offset.y
        )
        .transformable(state = state)
        .size(200.dp)
        .background(Color.Blue)
)
```

## SwipeToDismiss — свайп для удаления

```kotlin
@Composable
fun SwipeToDeleteItem(item: Item, onDelete: () -> Unit) {
    val dismissState = rememberSwipeToDismissBoxState(
        confirmValueChange = { value ->
            if (value == SwipeToDismissBoxValue.EndToStart) {
                onDelete()
                true
            } else false
        }
    )

    SwipeToDismissBox(
        state = dismissState,
        backgroundContent = {
            // Красный фон при свайпе
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .background(Color.Red)
                    .padding(end = 16.dp),
                contentAlignment = Alignment.CenterEnd
            ) {
                Icon(Icons.Default.Delete, contentDescription = "Удалить", tint = Color.White)
            }
        }
    ) {
        ItemCard(item)
    }
}
```

## NestedScroll — вложенный скролл

Управление конфликтами скролла между вложенными элементами:

```kotlin
// CollapsingToolbar эффект
val scrollState = rememberScrollState()
val toolbarHeight = 200.dp
val toolbarHeightPx = with(LocalDensity.current) { toolbarHeight.toPx() }
val toolbarOffsetHeightPx = remember { mutableStateOf(0f) }

val nestedScrollConnection = remember {
    object : NestedScrollConnection {
        override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
            val delta = available.y
            val newOffset = toolbarOffsetHeightPx.value + delta
            toolbarOffsetHeightPx.value = newOffset.coerceIn(-toolbarHeightPx, 0f)
            return Offset.Zero // не поглощаем скролл
        }
    }
}

Box(modifier = Modifier.nestedScroll(nestedScrollConnection)) {
    // Контент со скроллом
    LazyColumn(modifier = Modifier.fillMaxSize()) {
        items(100) { Text("Item $it") }
    }

    // Сворачивающийся тулбар
    Box(
        modifier = Modifier
            .height(toolbarHeight)
            .offset { IntOffset(0, toolbarOffsetHeightPx.value.roundToInt()) }
            .background(Color.Blue)
            .fillMaxWidth()
    )
}
```

## InteractionSource — реакция на состояния взаимодействия

Отслеживание нажатий, фокуса, hover для кастомных анимаций:

```kotlin
val interactionSource = remember { MutableInteractionSource() }
val isPressed by interactionSource.collectIsPressedAsState()
val isFocused by interactionSource.collectIsFocusedAsState()
val isHovered by interactionSource.collectIsHoveredAsState()

val scale by animateFloatAsState(
    targetValue = if (isPressed) 0.95f else 1f,
    label = "buttonScale"
)

Button(
    onClick = {},
    interactionSource = interactionSource,
    modifier = Modifier.scale(scale)
) {
    Text("Нажми меня")
}
```

## Частые ловушки

**1. Конфликт жестов — clickable и pointerInput:**

```kotlin
// ПЛОХО — оба обрабатывают нажатие, поведение непредсказуемо
Modifier
    .clickable { }
    .pointerInput(Unit) { detectTapGestures { } }

// Использовать что-то одно, или consume() в нужном месте
```

**2. Не вызывать change.consume()** — событие продолжит распространяться вверх по дереву и может быть перехвачено родительским элементом:

```kotlin
detectDragGestures { change, dragAmount ->
    change.consume() // обязательно если не хотим пробрасывать жест дальше
}
```

**3. pointerInput с изменяющимися ключами** — если ключ изменился, `pointerInput` перезапускает корутину. Если ключ — лямбда или объект, она пересоздаётся при каждой рекомпозиции:

```kotlin
// ПЛОХО — новая корутина при каждой рекомпозиции
Modifier.pointerInput(viewModel.state) { }

// ХОРОШО — стабильный ключ, обновляем через closure
Modifier.pointerInput(Unit) {
    detectDragGestures { _, dragAmount ->
        // читаем актуальные значения через remember-ссылки
    }
}
```

**4. Задержка clickable** — по умолчанию `clickable` ждёт чтобы различить одиночный и двойной клик. Если двойной клик не нужен — отключить:

```kotlin
Modifier.clickable(
    onClick = { },
    // не регистрируем onDoubleClick — задержки нет
)
```
