# Theming в Jetpack Compose

## Основа — MaterialTheme

MaterialTheme — точка входа в систему тем Compose. Предоставляет три системы через CompositionLocal:

- `MaterialTheme.colorScheme` — цвета
- `MaterialTheme.typography` — типографика
- `MaterialTheme.shapes` — формы углов

```kotlin
@Composable
fun MyApp() {
    MyAppTheme {
        Surface(color = MaterialTheme.colorScheme.background) {
            MainScreen()
        }
    }
}
```

## ColorScheme — цветовая схема (Material 3)

Material 3 использует систему из ~30 ролей цветов. Ключевые:

```kotlin
val LightColorScheme = lightColorScheme(
    primary = Color(0xFF6650A4),          // основной цвет (кнопки, FAB)
    onPrimary = Color.White,              // текст/иконки поверх primary
    primaryContainer = Color(0xFFEADDFF), // контейнер с primary оттенком
    onPrimaryContainer = Color(0xFF21005D),

    secondary = Color(0xFF625B71),
    tertiary = Color(0xFF7D5260),

    background = Color(0xFFFFFBFE),       // фон экранов
    onBackground = Color(0xFF1C1B1F),

    surface = Color(0xFFFFFBFE),          // фон карточек, диалогов
    onSurface = Color(0xFF1C1B1F),
    surfaceVariant = Color(0xFFE7E0EC),

    error = Color(0xFFB3261E),
    onError = Color.White,
)

val DarkColorScheme = darkColorScheme(
    primary = Color(0xFFD0BCFF),
    // ...
)
```

**Использование в компонентах:**

```kotlin
// Compose-компоненты автоматически берут цвета из темы
Button(onClick = {}) { Text("Кнопка") } // автоматически primary цвет

// Явное использование цветов темы
Text(
    text = "Заголовок",
    color = MaterialTheme.colorScheme.onSurface
)
Box(modifier = Modifier.background(MaterialTheme.colorScheme.surfaceVariant))
```

## Полная тема приложения

```kotlin
@Composable
fun MyAppTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    dynamicColor: Boolean = true, // Material You (Android 12+)
    content: @Composable () -> Unit
) {
    val colorScheme = when {
        // Dynamic Color — берёт цвета из обоев пользователя (Android 12+)
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S -> {
            val context = LocalContext.current
            if (darkTheme) dynamicDarkColorScheme(context)
            else dynamicLightColorScheme(context)
        }
        darkTheme -> DarkColorScheme
        else -> LightColorScheme
    }

    // Настройка цветов статус-бара
    val view = LocalView.current
    if (!view.isInEditMode) {
        SideEffect {
            val window = (view.context as Activity).window
            window.statusBarColor = colorScheme.primary.toArgb()
            WindowCompat.getInsetsController(window, view).isAppearanceLightStatusBars = !darkTheme
        }
    }

    MaterialTheme(
        colorScheme = colorScheme,
        typography = AppTypography,
        shapes = AppShapes,
        content = content
    )
}
```

## Расширение темы кастомными значениями

MaterialTheme не содержит всех нужных значений. Добавляем кастомные через CompositionLocal:

```kotlin
// Определяем кастомные цвета
data class AppColors(
    val success: Color,
    val warning: Color,
    val cardBackground: Color
)

val LocalAppColors = staticCompositionLocalOf {
    AppColors(
        success = Color(0xFF4CAF50),
        warning = Color(0xFFFFC107),
        cardBackground = Color(0xFFF5F5F5)
    )
}

// Расширение для удобного доступа
val MaterialTheme.appColors: AppColors
    @Composable get() = LocalAppColors.current

// Использование в теме
@Composable
fun MyAppTheme(content: @Composable () -> Unit) {
    val appColors = if (isSystemInDarkTheme()) {
        AppColors(success = Color(0xFF81C784), warning = Color(0xFFFFD54F), cardBackground = Color(0xFF2C2C2C))
    } else {
        AppColors(success = Color(0xFF4CAF50), warning = Color(0xFFFFC107), cardBackground = Color(0xFFF5F5F5))
    }

    CompositionLocalProvider(LocalAppColors provides appColors) {
        MaterialTheme(colorScheme = LightColorScheme, content = content)
    }
}

// В компонентах
Box(modifier = Modifier.background(MaterialTheme.appColors.cardBackground))
Text("Успех", color = MaterialTheme.appColors.success)
```

## Локальное переопределение темы

Можно переопределить тему только для части дерева:

```kotlin
// Инвертированная тема для шапки
MaterialTheme(
    colorScheme = MaterialTheme.colorScheme.copy(
        surface = MaterialTheme.colorScheme.primary,
        onSurface = MaterialTheme.colorScheme.onPrimary
    )
) {
    TopAppBar(title = { Text("Заголовок") }) // использует переопределённые цвета
}
```

## Частые ловушки

**1. Хардкодить цвета вместо темы** — при смене темы (тёмная/светлая) хардкоженные цвета не изменятся:

```kotlin
// ПЛОХО
Text(color = Color.Black) // не видно в тёмной теме

// ХОРОШО
Text(color = MaterialTheme.colorScheme.onSurface)
```

**2. staticCompositionLocalOf для часто меняющихся значений** — при любом изменении перекомпозирует всё дерево:

```kotlin
// Для темы (меняется редко) — staticCompositionLocalOf нормально
// Для часто меняющихся данных — compositionLocalOf
```

**3. Dynamic Color включён по умолчанию** — на Android 12+ цвета берутся из обоев. Если дизайн предполагает строгие фирменные цвета — отключить `dynamicColor = false`.

**4. isSystemInDarkTheme() в Preview** — в Preview тёмная тема не определяется автоматически. Явно передавать параметр:

```kotlin
@Preview(uiMode = UI_MODE_NIGHT_YES)
@Composable
fun DarkPreview() { MyAppTheme(darkTheme = true) { MyScreen() } }
```
