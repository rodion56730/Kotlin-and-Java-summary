## Аннотации @Parcelize

`@Parcelize` — основная аннотация из плагина `kotlin-parcelize`. Ставится над `data class`, и компилятор автоматически генерирует реализацию `Parcelable` (методы `writeToParcel`, `describeContents` и объект `CREATOR`). Класс при этом должен реализовывать интерфейс `Parcelable`.

```kotlin
@Parcelize
data class User(val id: Int, val name: String) : Parcelable
```

**`@IgnoredOnParcel`** — исключает поле из сериализации. Используется для вычисляемых или кешируемых полей, которые не нужно передавать. Поле должно иметь значение по умолчанию, иначе после десериализации оно будет `null`.

```kotlin
@Parcelize
data class User(val id: Int, val name: String) : Parcelable {
    @IgnoredOnParcel
    val tag: String = "user_$id"
}
```

**`@RawValue`** — разрешает сериализацию типа, который не является Parcelable (например, произвольный `Any`, сторонний класс). Фактически говорит компилятору «доверяю тебе, записывай как есть» через `writeValue`. Используется осторожно — если тип окажется несовместимым при десериализации, получим `ClassCastException` в рантайме.

```kotlin
@Parcelize
data class Wrapper(@RawValue val payload: Any) : Parcelable
```

**`@TypeParceler`** и **`@WriteWith`** — механизм для кастомной сериализации типов, которые не поддерживают Parcelable из коробки (например, `Uri`-обёртки, сторонние классы). Сначала описывается объект-сериализатор, реализующий `Parceler<T>`, затем он подключается через аннотацию.

```kotlin
object DateParceler : Parceler<Date> {
    override fun create(parcel: Parcel) = Date(parcel.readLong())
    override fun Date.write(parcel: Parcel, flags: Int) = parcel.writeLong(time)
}

@Parcelize
@TypeParceler<Date, DateParceler>()
data class Event(val date: Date) : Parcelable
```

## Аннотации Jetpack Compose

**`@Composable`** — ключевая аннотация всего Compose. Помечает функцию как composable-функцию, которая может описывать UI. Такую функцию можно вызывать только из другой `@Composable`-функции или лямбды с Compose-контекстом. Компилятор Compose трансформирует эти функции, добавляя механизм отслеживания состояния и перекомпозиции.

**`@Preview`** — позволяет просматривать composable-функцию прямо в Android Studio без запуска приложения. Поддерживает параметры: `showBackground`, `widthDp`, `heightDp`, `uiMode` (тёмная тема), `locale`, `fontScale`. Одну функцию можно пометить несколькими `@Preview` с разными параметрами.

```kotlin
@Preview(showBackground = true, uiMode = UI_MODE_NIGHT_YES)
@Composable
fun ButtonPreview() { MyButton("Click") }
```

**`@Stable`** — обещание компилятору, что класс стабилен: его публичные поля не изменятся незаметно, а если изменятся — Compose об этом узнает. Позволяет Compose пропускать перекомпозицию компонента, если входные параметры не изменились. Примитивы, `String`, `data class` с val-полями стабильны автоматически; классы с `var`-полями — нет.

**`@Immutable`** — более строгая версия `@Stable`: гарантирует, что объект полностью неизменяем после создания. Даёт компилятору максимальную возможность для оптимизации перекомпозиции. Используется для DTO, конфигурационных объектов.

**`@Remember`** — не аннотация, а функция, но концептуально связана: `remember { }` сохраняет значение между рекомпозициями. В паре с ней идёт `rememberSaveable { }` — сохраняет значение ещё и при пересоздании Activity (аналог `onSaveInstanceState`).

**`@State` / `mutableStateOf`** — `@State` как таковой нет, но `mutableStateOf()` создаёт наблюдаемое состояние, изменение которого автоматически вызывает перекомпозицию зависящих компонентов. Обычно используется в связке с `remember`:

```kotlin
var count by remember { mutableStateOf(0) }
```

**`@Composable` + `@ReadOnlyComposable`** — помечает функцию, которая только читает данные из Compose-окружения (например, `LocalContext.current`, `MaterialTheme.colors`), но не создаёт UI-узлов. Позволяет компилятору делать дополнительные оптимизации.

**`@CompositionLocalOf` / `@staticCompositionLocalOf`** — используются для создания `CompositionLocal` — механизма неявной передачи данных вниз по дереву компонентов (аналог React Context). `staticCompositionLocalOf` — для редко меняющихся значений (при изменении перекомпозирует всё дерево целиком), `compositionLocalOf` — для часто меняющихся (перекомпозирует только потребителей).

**Ключевые аннотации Compose в сводке:**

|Аннотация|Назначение|
|---|---|
|`@Composable`|Объявление UI-функции|
|`@Preview`|Предпросмотр в IDE|
|`@Stable`|Оптимизация перекомпозиции|
|`@Immutable`|Строгая неизменяемость, макс. оптимизация|
|`@ReadOnlyComposable`|Только чтение из Compose-окружения|
