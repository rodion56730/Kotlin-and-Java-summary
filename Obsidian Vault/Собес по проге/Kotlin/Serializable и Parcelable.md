## Serializable и Parcelable в Android

**Serializable** — стандартный Java-интерфейс-маркер (без методов). Чтобы класс стал сериализуемым, достаточно реализовать `implements Serializable`. Механизм работает через рефлексию: JVM автоматически обходит все поля объекта и записывает их в байтовый поток. Удобен в использовании, но медленен — рефлексия создаёт много временных объектов, что ведёт к дополнительной нагрузке на GC. Рекомендуется задавать `serialVersionUID` вручную, иначе он генерируется автоматически на основе структуры класса, и при её изменении (добавлении поля) десериализация старых данных упадёт с `InvalidClassException`. Подходит для сохранения объектов в файл, передачи по сети, но в Android считается медленным для передачи данных между компонентами через `Intent`/`Bundle`.

**Parcelable** — Android-специфичный интерфейс из `android.os`, оптимизированный для межпроцессного взаимодействия (IPC) и передачи данных через `Intent`/`Bundle`. В отличие от Serializable, разработчик сам явно описывает, как объект пишется в `Parcel` (`writeToParcel`) и как восстанавливается из него (через `CREATOR`). Никакой рефлексии — только прямая запись примитивов, строк и вложенных Parcelable-объектов, что делает его в разы быстрее Serializable. Из минусов — больше boilerplate-кода. На практике рутину генерирует плагин `@Parcelize` из `kotlin-parcelize`: достаточно добавить аннотацию над data class, и компилятор сгенерирует всю реализацию автоматически.

**Когда что использовать:**

- `Parcelable` — передача объектов между Activity/Fragment через Intent/Bundle, аргументы Fragment (`Bundle`), сохранение состояния в `onSaveInstanceState`. Это стандарт для Android.
- `Serializable` — сохранение объектов в файл или базу данных, работа с Java-библиотеками, ситуации, где важна простота, а не скорость.

**Ключевые отличия:**

|             | Serializable               | Parcelable                    |
| ----------- | -------------------------- | ----------------------------- |
| Реализация  | Автоматическая (рефлексия) | Ручная / `@Parcelize`         |
| Скорость    | Медленнее                  | Быстрее (в ~10 раз)           |
| Платформа   | Java (универсальна)        | Android only                  |
| Boilerplate | Минимальный                | Есть (снимается `@Parcelize`) |
| Применение  | Файлы, сеть, JVM           | Intent, Bundle, IPC           |
